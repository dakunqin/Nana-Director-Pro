参与贡献

先阅读 README、架构及验证报告。开发需要 Node 22.13+；建议 Node 24。

  1. 创建分支，执行 npm ci、npm test、npm run build。
  2. 行为变更请添加能复现问题的测试；界面变更验证窄屏，并更新实际截图。
  3. 提交前运行浏览器测试；涉及推理的变更记录模型、节点版本、硬件、参数和真实结果。
  4. PR 说明问题、修改行为和验证范围。不能用 HTTP fixture 结果代替 GPU 出片记录。

不要提交模型、运行环境、参考图、生成视频、数据库、私人路径、访问令牌或个人素材。示例剧本和图片须有明确授权。

新增资源必须给出可信原始来源、固定版本、SHA256、文件大小与许可；新增工作流先通过 object_info 预检和真实短片验证。不要默默启用云端推理或付费 API。

报告问题请提供系统/显卡/内存、安装方式、资源版本、重现步骤和已脱敏日志。请勿粘贴令牌或私人剧本。
