# 0.1.0 动态输入预检修复

用户实际连接 ComfyUI 0.43.0 后发现，数学节点的 `values` 被误报缺失。该节点通过 `COMFY_AUTOGROW_V3` 声明动态输入组，实际 API 工作流使用 `values.a`；旧预检仅匹配完整字段名。

修复：识别动态组下的扁平输入，检查模板允许的名称及最小输入数。未绑定、名称无效的动态组仍被拒绝。工作流图本身无需改动。

验证：新增两个回归用例，41 项核心/集成测试全部通过；使用用户当前实例的真实 `/object_info` 验证，数学节点误报消失，仅剩五个尚未安装的 H3 权重。

浏览器默认 Z-Image 示例中的 `qwen_3_4b.safetensors` 和 `z_image_turbo_bf16.safetensors` 为图像模型，合计约 18.96GB，与 H3 基础五模型不同。导演台通过 API 提交视频工作流，不依赖浏览器默认画布。

使用：先退出旧便携版，再打开文件名包含 `hotfix` 的修正版；使用同一个用户数据目录，项目和已下载资源不需要重新建立。然后到“模型中心”阅读模型许可并下载 H3 基础套件。真实 H3 出片仍待模型齐备后验收。
