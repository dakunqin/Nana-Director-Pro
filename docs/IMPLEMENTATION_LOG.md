实现决定：

- 复用上游 MIT 基础 standard 图，省去可选 Sage 编译节点，避免将尚未验证的编译依赖设为安装前提；性能需要实测。
- 模型许可受限时提示用户到来源处理；首版不存储 Hugging Face Token，可手动导入指定目录。默认公开文件已核查可访问。
- Python 间接依赖目前由固定节点的 requirements 解析，并记录 pip freeze；完整冻结环境留待兼容性验证后固定，跨日期安装可能存在差异。
- 工程实施由主代理在本会话直接完成，最终另做独立审阅。
- Windows 打包采用普通应用目录而非 ASAR，以避免当前构建环境中编辑大型 PE 完整性资源时的内存分配失败；安装包仍完整包含应用与媒体工具，代价是安装目录包含更多独立文件。
- 打包关闭主可执行文件资源编辑，窗口与安装器使用 Nana 图标，主 exe 的系统文件元数据/图标可能仍显示 Electron；压缩采用 store 以降低构建内存，代价是发行包体积增大。这两项属于预览分发取舍，可在资源充足的发布环境调整。
