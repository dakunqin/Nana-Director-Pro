安装与首次运行

适用版本：v0.1.22。更完整的界面操作见 使用手册。

下载与校验

从本仓库 Releases 下载 x64-setup.exe 或 x64-portable.exe，普通用户不需要源码 ZIP。两个 EXE 均为 Windows x64 程序，安装版便于固定使用；便携版每次启动会解包，可能较慢。

下载同一 Release 的 SHA256SUMS-0.1.22.txt，在 PowerShell 对照：

Get-FileHash -LiteralPath '.\Nana-Director-Pro-0.1.22-x64-portable.exe' -Algorithm SHA256

哈希值必须与发布校验文件完全一致。当前发行版未做代码签名；受设备或组织策略限制时，遵循本机安全策略，不需要关闭系统防护。

系统要求与容量

  • Windows 10/11 x64 为桌面发行目标；NVIDIA 为托管视频环境首要目标。
  • 其他 GPU/操作系统以实际后端兼容性为准，不承诺自动安装或完整 H3 视频支持。
  • 剧本编辑不依赖 GPU；CPU 本地导演受 RAM 和模型大小影响。
  • H3 基础五模型约 57.5 GB，此外需要环境、压缩包、解压、图片模型和作品空间。
  • 基础路线先预留至少约 80 GB，并为系统临时目录保留额外解包空间。该容量不是所有模型路线的上限。
  • 没有经过完整实测的 GPU/显存组合不列为保证兼容，详见 验证报告。

方案 A：托管环境

  1. 运行发行包，等待启动等待图、动画窗口和主界面检测结束。
  2. 在设置查看数据目录，若需更换先选择并重启。不要把更换路径当成自动迁移。
  3. 查看安装许可与资源信息，确认后执行环境安装。
  4. 等待下载、校验、解压、依赖安装和健康检查。安装失败查看阶段错误和日志，不要反复重启安装进程。
  5. 启动服务，保存设置并检测。
  6. 模型中心下载一个适合内存的本地导演模型，及 H3 基础五模型。
  7. 需要四视图时另选 FLUX.2 Klein 或 SDXL 图片路线，准备其全部组件。
  8. 下载完成后重启 ComfyUI 并重新检测资源。
  9. 创建项目，用短镜头验证真实生成。服务连通只是前提，不能代替真实推理测试。

托管服务使用数据目录内的独立运行环境，不向系统 Python 安装节点。只有安装成功且启用托管的服务会自动启动；不会自动接管外部服务。

方案 B：已有 ComfyUI / Ollama

  1. 手动启动自己的服务，确认没有端口冲突。
  2. 在设置填写 URL，常见为 http://127.0.0.1:8188 和 http://127.0.0.1:11434。
  3. 保存，重新检测。缺节点时按错误明确安装对应节点；节点存在仍需匹配参数结构。
  4. 核对模型搜索目录、文件名和套件。H3 文件名以应用模型中心及 resources/catalog.json 为准。
  5. 外部 ComfyUI 若要复用 Nana 数据盘模型，在该环境配置共享路径，并重启确认。
  6. 在设置选择已安装的本地导演模型。视频编码器不是 Ollama 导演模型，两者用途不同。
  7. ComfyUI 网页通过设置按钮按需打开，不会自动弹出。

本机地址保持 loopback 即可。主动连接其他设备时需要显式允许局域网，并自行管理网络范围；不建议把工作室服务暴露到公网。

离线使用

在可联网阶段下载并校验所需环境和模型，至少启动服务检查一次。随后可断网使用本地规划、素材/视频生成和导出。PayPal/微信二维码图片可离线显示，实际支付需要对应支付应用和网络。

数据位置、升级与卸载

默认数据目录为 %APPDATA%\Nana Director PRO\StudioData；自定义数据盘以设置为准。配置文件在同一应用用户目录内。便携程序的临时解包目录不是作品目录。

升级前退出旧版、等待当前任务完成并备份数据，再运行新版。卸载安装版不会主动清理作品数据目录；需要彻底清理时先自行核对与备份，不要误删模型和原始素材。

完整迁移、项目 ZIP 与恢复边界见 手册备份章节。
