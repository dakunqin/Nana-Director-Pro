# 0.1.10 设置命名、文档返回与紧凑性能栏

- “环境与设置”统一改为“设置”，包括左侧导航、状态图标提示和相关操作指引。
- OpenAPI 文档在软件内预览浮层显示，支持关闭按钮、Esc 和点击遮罩返回，不导航替换主界面。文档可滚动、选择和复制。图片与文档共用预览容器，通过 Portal 放到页面顶层，避免磨砂玻璃面板导致遮罩被裁切；关闭时恢复滚动和焦点。
