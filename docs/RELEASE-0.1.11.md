# Nana Director PRO 0.1.11

- 生成素材页面主标题改为“生成素材”。
- 项目卡片、当前工作空间和导演工作台支持重命名；重命名保留未保存的剧本草稿。
- 界面增加简体中文、繁体中文、英语、日语、韩语、西班牙语，首次默认跟随系统语言。手动选择保存到本机设置，切换前保存当前项目；界面翻译随软件安装，无需在线翻译服务，不改写项目内容。
- 剧本支持 TXT、Markdown、JSON 导入；分镜支持 JSON、CSV 导入。先预览校验，再勾选确认覆盖；CSV 可由 Excel 另存为 UTF-8 CSV。此版不直接读取 DOCX/XLSX。
- 分镜导入检查时长、素材引用与项目版本，并重新分配镜头 ID，避免旧视频误归属到新镜头。旧文件保留。

验证：69 项服务端测试、31 项浏览器界面测试通过；TypeScript、生产构建、多语言覆盖检查和桌面启动检查通过。没有执行新的 GPU 模型推理或质量评估。
