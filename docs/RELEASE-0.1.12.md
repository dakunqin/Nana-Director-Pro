# Nana Director PRO 0.1.12

- 项目设定场景列表增加内部滚动条及高度限制，添加按钮保留在列表外；添加新场景后自动滚动至列表底部。
- 四视图提交和生成过程中显示旋转图标与流动进度动画，当前任务提示紧贴生成按钮下方，已有草稿排列在后。
- 审核入库后持久记录入库时间、资产 ID 和采用视图，默认移入可展开的“已入库记录”，不再显示待审阅或重复入库按钮。
- 旧版入库记录会在启动时尝试通过素材库中完全相同且晚于生成图片创建的独立副本识别。文件缺失或无法确定的记录保留原状，不删除素材。
- 素材库每个资产卡片新增“生成四视图”入口，自动带入现有名称、描述和资产类型，无图片时按文字生成；入库绑定到原资产，不新增同名角色。
- 增加道具四视图类型，FLUX 和 SDXL 均使用物品外观与几何提示词。生成所需模型和节点仍需已安装。

验证：70 项服务端测试、33 项完整界面回归测试通过；随后补充自动滚动与可见滚动条后，两项相关界面回归再次通过。TypeScript、生产构建、多语言覆盖与独立桌面启动检查通过。测试使用模拟图片引擎，没有运行新一轮 GPU 推理或验证模型画质。
