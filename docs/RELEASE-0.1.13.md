# Nana Director PRO 0.1.13

- 导演工作台按项目记住最后选中的镜头，离开到生成队列再返回以及同一会话刷新页面后保留选择；被删除的镜头回退到当前第一个镜头。
- 视频任务显示 HH:MM:SS 计时。排队阶段显示等待时间；开始资源预检后显示耗时，含预检、提交、引擎生成和归档。成功、失败、取消或中断时停止计时。旧记录有足够时间字段时沿用，无记录时不编造历史耗时。
- 每个视频任务增加 ComfyUI 工作流查看入口，展示节点和连接，并可展开完整 JSON 或下载。尚未处理的任务根据入队时保存的参数生成预览；参考图上传名称、上一镜头尾帧可能在实际提交时变化。生成过实际工作流后展示保存的任务版本，不根据当前项目改写。
- 资源预检、提交、生成、归档中的镜头任务显示旋转动态图标。顶部性能栏增加动态活动小图标；读取失败时停止动画，读数仍约每三秒刷新。
- 新增本机接口 GET /api/v1/jobs/{id}/workflow，仅返回实际工作流或任务快照预览，不提交生成任务、不上传图片。

验证：72 项服务端测试、34 项界面测试通过；TypeScript、生产构建、界面翻译覆盖和独立桌面启动检查通过。工作流弹窗可通过关闭按钮或 Escape 返回。测试没有调用真实 GPU 视频推理。
