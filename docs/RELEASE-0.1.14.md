# Nana Director PRO 0.1.14

- 顶部性能条的内存、每张 GPU 利用率和显存分别增加带动态线条的三角小图标；保持固定单行显示，读取失败或数值不可用时停止对应动画，遵循系统减少动画偏好。动态图标表示资源监测活动，实际占用以旁边数字为准。
- “生成此镜头”旁增加 ComfyUI 工作流查看入口，使用当前编辑中的镜头、画幅、声音和生成方式生成只读预览，不保存草稿、不提交生成任务、不上传参考图。队列仍显示任务快照对应的实际工作流。
- 镜头设定增加“声音输出”：默认无声输出，可选择 H3 原生声音。原生声音支持独立填写声音描述，包括环境声、对白内容和语言要求；语言和台词准确性受模型能力影响，不是单独 TTS 配音功能。
- 无声模式在 VHS 合成时不连接模型音轨，确保新镜头文件无模型声音；模型内部仍使用兼容的原生音视频工作流，并不承诺节省声音推理资源。已生成视频和已经提交的工作流不修改。成片拼接可能为格式兼容补入静音音轨。
- 自动规划的新镜头默认无声，人工锁定镜头的设置随原镜头保留。声音设置保存在项目和任务快照中，支持 JSON 项目/分镜导入。
- 新增本机 POST /api/v1/projects/{id}/workflow-preview 接口，校验草稿及声音参数，只返回工作流预览。

验证：74 项服务端测试、35 项完整界面回归通过；TypeScript、生产构建、多语言覆盖及桌面启动检查通过。只读检查确认当前本机 ComfyUI 的 VHS_VideoCombine.audio 是可选输入。本轮没有提交新的 GPU 推理，未验证原生对白画质或语言准确性。
