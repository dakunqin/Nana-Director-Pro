# Nana Director PRO 0.1.15

- 性能条改为按真实百分比填充的长条，分别显示 CPU、内存、每张 GPU 和显存占用；不可读时显示空条及状态，不再使用三角图标。读数更新时平滑调整比例。
- 项目设定增加 4:3 横屏、3:4 竖屏、3:2 横屏、2:3 竖屏和 21:9 超宽屏；原有 16:9、9:16、1:1 保留。新增画幅应用于工作流与成片导出。
- 生成分辨率增加 0.9 MP 和 1.1 MP。
- 采样器增加 dual_clock_euler（默认）、euler、euler_ancestral、heun、dpmpp_2m、dpmpp_2m_sde。采样步数默认 4，允许 1–1000 整数，实际质量和耗时取决于模型与采样器。
- 输出帧率默认 24 fps，可选择 12、15、24、25、30、48、50、60 fps。H3 原生工作流仍按 24 fps 生成，其他输出帧率在归档时用内置 FFmpeg 转换，保留时长与音轨；这不是运动插帧，不产生新的模型运动细节。导出成片使用项目当前输出帧率。
- 新参数进入不可变任务快照，编辑项目不会修改已排队任务的采样和输出帧率。旧项目缺少新字段时沿用原有默认值。

验证：78 项服务端测试、36 项完整界面回归通过；TypeScript、生产构建、多语言覆盖和独立桌面启动检查通过。真实 FFmpeg 验证了 24→30 fps、时长/音轨保留及 4:3 成片导出；本轮没有运行新的 GPU 模型推理。
