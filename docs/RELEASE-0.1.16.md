# Nana Director PRO 0.1.16

- 顶部 CPU、内存、GPU、显存占用条改为竖条，自底向上按实际比例填充。未知读数保持空条，不制造虚假占用动画。
- 左侧“生成队列”在资源预检、提交、引擎生成或归档期间显示旋转图标，保留任务数量；只有等待任务时不显示运行旋转。
- 修复尾帧衔接仅查找相同 requestKey、导致单独提交镜头无法衔接的问题。现在按入队时的分镜顺序快照，定位紧邻的同场景上一镜头，支持分批或单镜头生成。
- 同批次优先使用该批次前镜头；前镜头失败或未完成时明确报错，不误用旧版本或静默改为普通生成。不同场景或场景首镜头不衔接，并显示说明。
- 尾帧缺失时从上一镜头视频重新提取；缺少视频、无法提取时明确失败。修正 FFmpeg 提取逻辑，取结尾窗口反序后的第一帧，即最后一帧，而不是结尾前约 0.1 秒的一帧。
- 衔接尾帧接入 H3 first_frame；其余资产图片仍作为身份参考。任务记录来源任务和是否实际接入，队列显示说明。工作台及排队预览包含对应首帧占位节点。
- 尾帧占用一个图片输入，因此衔接时最多再使用八张资产参考图。

验证：82 项服务端测试、37 项完整界面测试通过；真实 FFmpeg 短视频核对提取图片与最后一帧完全相同。覆盖跨批次衔接、缺少前镜头时阻止提交、同批次失败不误用旧版本、竖条比例及导航运行/等待区分。TypeScript、构建、多语言覆盖、独立桌面启动检查通过。本轮没有运行新的 GPU 视频生成，未评价模型画面连续性的强弱。
