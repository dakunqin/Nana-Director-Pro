# Nana Director PRO 0.1.17

- 顶部状态行新增“队列耗时”，按秒刷新，显示当前批次任务的累计处理时间，不含排队等待，不累加历史批次；完成后停止增长。点击可前往生成队列。
- 性能条的比例图标改为下宽上尖的三角形，仍从底部按实际占用比例填充，不使用假进度。
- Windows 打包改为最大压缩。删除重复的 React、图标、OpenCC 等运行时目录（其代码已包含在前端构建中），旧版前端构建、非 Windows x64 解压工具和不支持语言的 Electron 资源；保留必要浏览器、GPU/视频组件、FFmpeg、7-Zip、六种语言及完整许可文本。
- 增加可重复执行的打包后精简流程，核验目标位于本项目 release 子目录内，仅处理打包输出。用户项目、模型、源码依赖和当前运行环境不删除。
- 同一构建展开体积从 498.6 MiB 降至约 395.3 MiB。便携版从旧版约 523.7 MB 降至约 125.4 MB，减少约 76%；安装版约 137 MB（MB 为十进制）。保留独立运行能力，模型仍单独下载。

验证：82 项服务端测试、38 项界面回归通过；TypeScript、生产构建、多语言覆盖通过。精简后的桌面版实际完成视频导出、最后一帧提取、7-Zip 备份及离线繁体转换验证；保留沙箱预加载和独立本地服务。本轮没有执行新的 GPU 模型推理。
