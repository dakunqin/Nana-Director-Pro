# Nana Director PRO 0.1.19

- 单独点击“生成此镜头”后留在导演工作台，自动滚动至审片监视器。监视器附近即时显示已提交任务的等待、生成或失败状态。生成全部镜头仍使用队列流程。
- “镜头设定”标题行增加“生成此镜头”按钮，与底部按钮共享可用状态、提交参数和行为。
- 尾帧功能改为“可选镜头尾帧”。启用后默认自动选择分镜顺序中最近已完成的前序镜头；批量任务优先衔接本批次前序镜头。也可手动选择当前项目的其他已完成镜头，包括其他场景或当前镜头已完成的历史版本。
- 列表为每个镜头的最近已完成版本。手动选择记录具体来源任务 ID，排队后不改成其他来源；跨项目或未完成来源被拒绝。尾帧缺失时保留原有重新提取与明确报错机制。
- 本机及 Agent 提交接口新增可选 tailSource：auto 表示自动，其他值为已完成来源任务 ID。省略时兼容旧的同场景相邻镜头规则；重试保留手动来源。
- 工作流预览同时反映尾帧选择，尾帧作为首帧输入，资产参考图仍按选定生成方式处理。沿用精简独立包。

验证：85 项服务端测试、41 项完整界面回归通过，覆盖真实 API 参数传递、跨场景来源、项目隔离、自动前序选择、上下两个生成按钮、停留工作台和滚动位置。TypeScript、生产构建、多语言检查通过；精简桌面版通过启动、实际视频导出、尾帧提取、备份及离线繁体切换。本轮没有执行新的 GPU 模型推理。
