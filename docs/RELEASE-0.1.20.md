# Nana Director PRO 0.1.20

- 修复导出缺少明显结果反馈的问题：导出成片后留在工作台，自动滚动至结果面板，保证下载按钮可见，显示旋转图标、阶段进度、失败原因及“下载成片”。同一导出进行时禁用重复提交；队列页操作记录移至视频任务列表前方。
- FFmpeg 导出逐镜头报告处理数量与进度，随后显示合并和保存阶段。导出操作记录项目 ID，返回工作台仍可找到最近结果；兼容旧记录的结果路径关联。正确区分完成、失败、取消和中断状态。
- 默认声音改为 H3 原生声音，适用于新生成及未指定声音的镜头。已有明确保存的无声选择仍保留，可手动切换。
- 提示词默认采用以下结构，原提示词完整保留：

```text
integrated_multimodal_description: 原提示词内容

overall_soundscape: N/A

non_diegetic_music: N/A
```

- 已有普通提示词在读取时按格式展示，保存项目时写入新格式；已经采用此格式的内容不重复嵌套，已有环境声和音乐描述不覆盖。手动新镜头、自动规划和分镜导入均采用相同格式。视觉描述为空时不能提交生成。
- 工作流将镜头语言和参考图对应关系追加到视觉描述部分；单独填写的声音描述补充到 overall_soundscape。已有生成的视频与任务产物不修改。
- 沿用精简独立打包，模型继续按需下载。

验证：88 项服务端测试和42项完整界面回归通过，补充检查导出取消终态。覆盖真实 FFmpeg 导出进度、API 项目关联、工作台进度/完成下载/失败、提示词原文与幂等、新音频默认值。TypeScript、构建、多语言检查和精简桌面实际导出、尾帧、备份、离线繁体检查通过。本轮没有执行新的 GPU 模型推理。
