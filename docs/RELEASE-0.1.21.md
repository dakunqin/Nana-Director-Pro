# Nana Director PRO 0.1.21

- 下载成片默认采用当前项目名称，保留中文；自动处理文件名非法字符、Windows 保留名称和过长名称。新导出文件本身使用项目名，历史 film.mp4 结果下载时也采用当前项目名称。
- “导入剧本”移到“剧本 / 项目设定”标题行，“导入分镜”移到“分镜序列”标题行，原有预览与确认导入流程保留。
- 分镜支持上下拖动至任意位置，显示拖动手柄与插入位置提示，列表边缘支持自动滚动；也可聚焦分镜后按 Alt+上下方向键移动。新增空白分镜可以先调整位置，再填写内容。
- 调整排序保留镜头 ID、内容、引用资产、选择状态和已有生成视频；序号随顺序更新。点击“保存剧本”持久保存，后续导出按新顺序排列。
- 沿用精简独立打包，模型按需下载，原项目数据保持兼容。
