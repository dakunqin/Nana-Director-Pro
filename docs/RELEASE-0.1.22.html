Nana Director PRO 0.1.22

  • 修复便携启动等待图未显示：此前 splash.bmp 实际是 PNG 编码，启动器不支持；改为真实 24 位 BMP，并加入格式回归测试。scripts/prepare-splash.ps1 可按当前版本重新生成。桌面动画等待窗至少显示 1.2 秒，避免快速启动时一闪而过。
  • 修复点击示例剧本后黑屏：存在历史任务而当前项目尚无分镜时，任务选择逻辑错误读取空 queuedTask。现先判断对象存在；新增无分镜项目也受此修复覆盖。
  • 示例按钮改为打开或创建唯一示例入口，重复点击、重启、重命名后继续复用，不覆盖已编辑内容。兼容旧版本同名示例；仅合并同名、同剧本、没有分镜/素材/任务的未使用重复副本，保留已修改或有产物的项目。
  • 左下角新增“关于”，软件版本、作者 Dakun Qin、邮箱 qindakun@yahoo.com 及开源署名从设置移入关于。设置保留运行环境、模型、Agent、语言和外观选项。
  • 关于新增 PayPal 与微信两种自愿捐赠路径，使用用户提供的原始二维码图片，离线打包，不请求外部支付服务。点击放大，关闭按钮、背景或 Esc 返回页面。
  • 保留精简打包方式及既有项目数据路径。

验证：93 项服务端测试、45 项界面测试，TypeScript、多语言覆盖和生产构建。精简桌面检查覆盖动画启动窗、历史任务下示例打开、二维码资源、真实 FFmpeg 导出/尾帧、7-Zip 备份与离线繁体。无新 GPU 模型推理、无支付交易。
