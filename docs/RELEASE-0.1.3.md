# 0.1.3 引用资产与人物一致性修正

旧行为：引用资产不等于引用图片；文生视频未使用图片；参考图模式缺图时按钮禁用，但没有足够说明。

新行为：默认自动选择，每个镜头引用资产时使用参考图，无引用资产时文生视频。缺图片时不会退回文生视频，列出缺图资产名称并提供素材库入口。资产列表显示图片绑定状态与缩略图。服务端验证图片文件存在，拒绝参考图模式零资产的静默文生回退。

生成方式：自动选择、参考图模式（Ref2VA）、首帧图生视频（I2VA）、文生视频（T2VA）。首帧模式按资产列表顺序将第一项已勾选图片作为首帧，其余图片作为参考（Hybrid）。首帧模式与上一镜头尾帧衔接互斥。尾帧衔接只作用于同一批次同场景中的上一已完成镜头。

图片提示词增加明确的图片编号、资产名称和外观描述对应关系。身份保持仍取决于模型生成效果，需要小样审片，不能保证绝对一致。

使用：先到素材库上传角色定妆图，再到镜头勾选该资产，选择自动或参考图模式。需要从具体构图开始时使用首帧模式。

验证：53 项核心测试、11 项浏览器测试通过。包含真实图片绑定后按钮解锁、所选图片上传到模拟 ComfyUI 并进入 Ref2VA 工作流，以及 I2VA/Hybrid 的首帧与参考编号检查。未运行新的 GPU 出片，未据此声称实际身份保持效果已验证。
