# 0.1.4 素材生成与暗亮风格

在素材库新增本地四视图生成器：人物、动物、场景。支持从当前素材库选择已有图片，或上传 PNG/JPEG/WebP 参考图。无参考图时文生图，有参考图时通过 LoadImage → ImageScale → VAEEncode 接入 SDXL 图生图流程，参考图片不是只在界面展示。

生成方式为单张 1024×1024 的 2×2 四视图草稿，再由本机 FFmpeg 裁切四张分图。人物动物预期为正、背、左、右；场景预期为四个方向。此流程是扩散模型的二维参考图生成，并非严格三维重建或身份锁定。模型可能画错朝向或不一致，用户需审阅预览后再入库；界面明确标注“预期”方向，不将象限裁切当成语义验证。

入库可新增素材或替换已有素材参考图，选择整张四视图或单张视图；动物以角色类资产存储以兼容现有导演流程。即使尚未规划剧本，也能先生成素材，资产草稿可保存，模型输出规划仍须包含有效镜头。

本地模型：默认 SDXL Base 1.0，约 6.94 GB。模型中心新增独立图片模型入口，固定官方版本与 SHA256 校验，不随软件打包，不使用付费 API。已有兼容 SDXL checkpoint 可在生成器中选择。托管 ComfyUI 已加入 checkpoints 模型路径；下载后重启 ComfyUI 并重新检测。外接服务需自行放入该服务的模型目录。

来源与许可：https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0 （CreativeML Open RAIL++-M，与本软件许可独立）。固定版本 462165984030d82259a11f4367a4eed129e94a7b，SHA256 31e35c80fc4829d14f90153f4c74cd59c90b779f6afe05a74cd6120b893f7e5b。

右上角新增明暗快速选择，暗色森林、暗色午夜蓝、亮色暖灰；与环境设置同步并记住当前设备选择。

验证：58 项核心测试、13 项浏览器测试、类型检查和生产构建通过。用真实 FFmpeg 验证图片裁切；模拟 ComfyUI 验证参考图上传、工作流提交、恢复和入库。实际本机 ComfyUI 节点定义核对显示所需节点兼容，但当前缺少 SDXL checkpoint，尚未完成真实 GPU 四视图出图质量验证。不会自动下载大模型或操作用户正在使用的生成任务。
