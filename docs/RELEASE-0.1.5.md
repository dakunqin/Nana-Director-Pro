# 0.1.5 下载入口与固定顶部栏

图片模型下载不再被 H3 区域的许可勾选项禁用。点击“下载图片模型”直接显示该模型的大小、官方来源与许可证，点击“同意许可并开始下载”后按既有本地下载器下载和 SHA256 校验。该操作与 H3 模型许可选择独立。暂停、断点续传与错误显示沿用下载器。

顶部删除“明暗”文字，保留风格选择框；新增极简白、石墨黑、磨砂玻璃，与原有森林、午夜蓝、暖灰共六种，保存后重启恢复。风格方向参考近年常见的极简和玻璃界面设计，并无统一的“最流行”排名。设计参考：https://pros.squarespace.com/blog/design-trends 、https://trends.daisyui.com/ui-design-trends-2026/ 。

硬件资源读数放在顶部栏中间，顶部固定，滚动时保持可见。点击资源读数展开详情。多显卡和小屏幕提供紧凑布局；窄屏隐藏部分导航文字并保留菜单与风格选择。

验证：类型检查、生产构建、16 项浏览器测试通过，包括下载确认请求参数、三种新风格重载恢复、顶栏位置固定与手机无横向溢出。下载测试拦截网络请求，未自动下载 6.94 GB 模型。构建后检查独立桌面启动及内置工具。
