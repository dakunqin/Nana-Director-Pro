# 0.1.6 模型管理、素材删除与运行反馈

## 素材质量方案调整

默认改为 FLUX.2 Klein Base 4B FP8 参考图编辑，四个角度分别生成，再合成为总览。无参考图时，先生成正面，其他三个角度使用正面图的参考潜变量；有参考图时，四个角度都使用该参考。人物、动物、场景均可选。旧 SDXL 四格裁切流程保留为基础兼容选项，并明确标注人物质量较弱，不再作为推荐方案。

官方方案来源：https://blog.comfy.org/p/flux2-klein-4b-fast-local-image-editing ，节点与连接参考 https://github.com/Comfy-Org/workflow_templates/blob/main/templates/image_flux2_klein_image_edit_4b_base.json 。本软件根据业务需求构建四个方向图，不包含官方工作流中的示例照片。

模型中心新增三件套下载：FLUX.2 Klein Base 4B FP8、Qwen3 4B 编码器、FLUX.2 图片 VAE，合计约 12.38 GB。官方模型仓库 metadata 校验了固定版本、文件大小、SHA256 和各自 Apache-2.0 许可。只通过用户点击下载，不自动下载权重。

本机节点定义预检显示新工作流的节点及连接兼容，当前缺少上述三份权重。没有进行真实 GPU 出图质量验证，不能保证四视图身份或朝向绝对一致。

## 自定义模型

模型中心可导入本地 safetensors/ckpt/pt/pth/gguf/bin 文件，按 checkpoint、扩散模型、编码器、VAE、LoRA、视觉编码器、ControlNet、Embedding、音频编码器、放大模型分类。流式传输，不把大模型整体读入内存；显示进度，计算 SHA256，不覆盖已有同名文件。默认上限 200 GB。导入目录会加入托管 ComfyUI 共享路径，导入后重启并重新检测；外部服务需配置共享目录。导入任意模型不代表它与任意生成方案通用，素材生成器允许选择对应的扩散模型、编码器与 VAE。

Ollama 支持自定义本地模型标签下载，已安装模型会加入导演模型选择。继续禁止 cloud 标签与远程服务地址。自定义模型需具有本地结构化输出能力，模型生成的计划仍进行严格验证。

## 删除素材

生成草稿提供删除按钮，删除该草稿和其四张分图，不影响已入库的独立副本。素材库提供直接删除按钮，删除绑定图片并解除镜头引用，已生成视频保留。生成进行中拒绝删除正在使用的素材。

## 启动与服务反馈

便携版解压显示启动图片；Electron 启动后先显示加载窗口，再进入工作室。读取项目和配置后先显示界面，不再等待全部服务与硬件检测。检测中明确说明“请等待，检测不代表未安装”，避免误导用户重复安装。

服务控制提供“启动服务”“停止托管服务”“检测服务连接”文字按钮。点击后显示正在执行、等待连接、连接结果或失败信息；启动后等待服务响应，超过两分钟引导看日志。停止服务等待本应用启动的进程退出，不关闭外部程序启动的服务，并明确提示外部服务仍在线。

## 验证

62 项核心测试、18 项界面测试、类型检查与生产构建通过。真实 FFmpeg 验证四图合成与旧版裁切；模拟 ComfyUI 验证任务提交、参考潜变量、结果查收和入库。模型导入、素材删除、检测等待文字均有界面回归。新模型的实际人物效果尚待下载后小样验证。
