# 0.1.7 静默复检与按需打开 ComfyUI

日期：2026-11-01

- 托管 ComfyUI 的日常启动和安装健康检查显式使用 --disable-auto-launch，禁止自动弹出网页。环境设置提供“打开 ComfyUI 网页”按钮，桌面端通过受限制 IPC 打开已保存的本地/允许局域网地址，仅点击时执行。
- 后台每轮复检保留已有准备结果，不再将整块面板反复替换成加载画面；后台连接错误保留上次结果，手动生成前仍进行强制预检，避免仅靠旧状态提交。
- 首次检测显示旋转动画和“正在检测本机服务与模型，请等待”。已安装且配置托管的服务在启动初期保留最多两分钟等待窗口，避免服务尚在加载时立刻显示缺失；超时后按实际检测结果提示。总览的服务徽标在初次检测期间也显示“正在检测”。
- 资源就绪后显示“已就绪，可以生成”和“可以生成视频”，不再显示“建议先生成 5 秒小样”。资源就绪仍仅代表前置检查通过，不代表此前已经验证过某台机器的真实出片质量。
- 便携启动图片改为“正在启动，请稍候…”，加载小窗口不再用解压作为主要提示。

验证：63 项核心测试、21 项界面测试、类型检查与生产构建通过。覆盖后台复检时面板保持可见、首次等待动画、就绪提示、ComfyUI 打开按钮仅在点击后调用，以及启动参数禁止自动网页。
