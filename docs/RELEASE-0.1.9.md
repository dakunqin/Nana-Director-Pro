# 0.1.9 图片预览返回与状态布局

- 顶栏当前项目名称前增加“项目：”。
- 左侧菜单从“生成四视图素材”改为“生成素材”，内部仍提供四视图生成。
- 生成的图片改为软件内浮层预览，支持关闭按钮、Esc 和点击遮罩返回，不会替换工作室页面；长名称不会挤走关闭按钮。桌面端也保护旧图片链接，单独打开预览窗口或下载，避免主界面被图片覆盖。
- 便携启动图片删除“首次打开需要一些时间，请勿重复点击”，加载小窗口也删除此类重复说明，仅保留启动与必要状态提示。
- 默认窗口宽度提高到 1920，按屏幕可用宽度适配。顶栏右侧按内容分配空间，“本地运行”和显卡名称禁止折行，其他资源信息保持单行。
- 准备状态信息框仅出现在“工作室总览”和“环境与设置”。所有页面顶栏均提供状态图标，区分检测中、已就绪、需准备和失败；点击进入环境与设置查看详情。生成前的实际检查仍保留，相关提示已改为指向顶栏图标。

验证：类型检查、生产构建与 25 项界面回归通过，覆盖图片预览关闭和 Esc 返回、状态框显示范围、状态图标导航、菜单名称、项目名前缀、顶栏单行和移动布局。生成算法与模型未改变。
