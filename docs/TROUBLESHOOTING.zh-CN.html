故障排查与问题反馈

适用版本：v0.1.22。先确定问题发生在哪一层：程序启动 → 服务连接 → 资源检测 → 工作流执行 → 输出归档 → 成片导出。避免把所有错误都归因于“模型没装”。

先收集四类信息

  1. 软件版本、安装版/便携版、操作系统与 GPU/显存/RAM。
  2. 实际数据盘、可用磁盘、使用托管还是外部 ComfyUI/Ollama。
  3. 最短重现步骤、任务状态、错误原文与发生时间。
  4. 设置中的相关日志，任务工作流中的模型与参数。公开前删除令牌、私人路径与剧本。

检测与服务

检测中不等于缺失

首次启动几秒内，顶栏图标可能旋转，设置会显示检测等待。后台检测不会不断重建资源卡片。检测超时会显示失败并提供重试；等待本轮结束后再判断。

服务地址连接失败

  • 确认服务已启动且地址/端口正确。
  • 托管服务在设置启动；已有外部服务需要由其启动器管理。
  • 确认当前浏览器页面不是另一个旧服务的端口。
  • 只读查看日志，优先修复明确的依赖或端口错误。
  • 本应用的“暂停/停止服务”不代表能够关闭你另行启动的 ComfyUI。

服务连接成功但仍不能生成

ComfyUI 连通、必需节点存在、模型存在、输入结构正确是不同检查项。查看预检缺项，不要仅凭 ComfyUI 网页能打开就认为工作流齐全。

下载与模型

下载按钮不可用

先看是否尚未完成对应模型的许可确认、是否已有安装/下载任务、是否在等待检测。图片模型和 H3 的许可入口分别处理。

网络中断或校验失败

支持暂停和恢复。恢复时会处理服务器 Range 支持差异。校验失败的文件不会被当成有效权重；不要把临时文件改名绕过校验。来源被网络限制或需要许可授权时，在原站确认后手动下载到正确目录，再检查。

自定义模型导入后未显示

核对类别、文件扩展名、目标目录、外部 ComfyUI 模型搜索路径。重启 ComfyUI，再回软件重新检测。导入任意文件只是保存，不会自动替换内置视频架构。

Ollama 规划失败

  • 选定模型是否已经下载，服务是否实际能加载。
  • GPU 显存与系统内存是否被其他程序占用。
  • 改用较小模型或 CPU 规划；CPU 也需要足够 RAM。
  • 模型输出结构错误时，应用会进行有限修复；仍失败可缩短剧本、手动编辑或导入分镜。
  • 不使用 cloud 标签，不回退到付费 API。

素材与一致性

参考图模式按钮灰色

检查是否至少引用一个有图片的资产。只有文字资产条目不算参考图。确保引用资产没有缺图，视觉提示词不为空，服务已就绪；首帧模式与尾帧不能冲突。

选择资产后还是换了人物

先确认不是文生视频。检查镜头实际工作流是否包含参考输入，图片是否清晰、单主体，提示词是否与参考服装/年龄冲突。参考输入不是身份锁，仍需人工审片。

四视图质量差或朝向错误

SDXL 四格兼容路线的人物质量较弱。尝试 FLUX 四角度参考编辑，使用干净的参考图、明确外观与朝向；筛选后再入库。不要把错误草稿直接用于所有镜头。

已入库条目还想查看

使用显示已入库记录的选项。待审核与已入库是不同状态；如仍出现错误标记，记录草稿 ID、操作步骤和版本反馈。

任务与性能

GPU 使用率低但任务没结束

可能在 CPU 规划、模型加载、传输、保存或 FFmpeg 处理。查看任务阶段和日志，不只盯着 GPU 数值。性能条是整机采样，不是进程级计费仪表。

OOM / 系统资源不足 / WinError 1450

保留任务记录，减少分辨率、时长与并行作业，选择更小导演模型。多卡显存不能简单相加。不要随意结束别人的 ComfyUI 或任务；先确认占用来源。硬件检测不是内存充足保证。

任务提交后卡住或软件异常退出

查看任务是否已经得到 promptId。应用会尝试恢复已知历史；对提交结果未知的状态，不会擅自重复消耗 GPU。先检查 ComfyUI 历史与输出，再决定是否重试。

取消后 ComfyUI 仍在计算

应用避免对共享服务发送全局中断。已提交任务可能继续执行并归档，取消待提交任务与中断整个 ComfyUI 是不同操作。

尾帧、声音与导出

尾帧不起作用

确认勾选可选镜头尾帧，来源是当前项目已完成的镜头，源视频文件仍存在，模式没有与首帧图生视频冲突。默认自动寻找当前分镜之前最近已完成镜头；调整分镜顺序后保存。提取失败应查看错误，不用仅凭视觉猜测。

没设配音却出现人声或方言感声音

默认 H3 原生音频会自主生成声音；N/A 不是静音。需要确定无声，选择“无声输出”，保存并重新生成。声音描述只提供引导，不是精确 TTS；旧视频不随新设置改变。

点击导出后没有自动下载

导出是先处理，后点击下载。查看工作台成片结果及队列顶部操作记录：是否运行、失败或已完成。完成后主动点“下载成片”，检查浏览器下载列表。默认文件名为当前项目名，不再固定 film.mp4。

缺镜头或顺序不对

保存分镜顺序，确认各镜头有成功归档结果。部分导出会跳过未完成项；完整导出需要全部可用。导入分镜会生成新镜头 ID，旧视频不会自动绑定为新镜头的结果。
