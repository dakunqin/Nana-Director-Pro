## 本版具体修复证据

- 旧 splash.bmp 检查到 PNG 签名；改为真实 BMP 的 BM 签名与 24 位像素格式，加入回归测试。
- 旧版在有历史任务、当前无分镜时尝试读取空 queuedTask；浏览器用例先复现，再验证修复后可以进入工作台。
- 示例入口新增持久关联、历史同名兼容与安全去重；重命名后继续复用，修改过的重复项目不删除。
- 成片中文文件名、UTF-8 下载响应、旧 film.mp4 下载兼容与真实 FFmpeg 产物名称已有测试。
- 分镜拖动保留当前选择、ID 和内容，保存重开保持顺序；工作台生成后停留和滚动已有 UI 回归。

## 已有本地模型验证

历史基线中，独立 Ollama 的 qwen3:1.7b 在 CPU 实际完成短剧本结构化规划，约 81.8 秒，4 场景、4 镜头、3 资产；人工审阅发现小模型仍会过度拆场或改写内容。

托管环境下载、校验、解压、节点依赖安装和独立 ComfyUI CPU object_info 曾实际验证；部分高负载重试遇到系统资源不足。以上是环境/规划事实，不是 H3 GPU 视频质量结论。细节保留在 [v0.1.0 历史报告](VALIDATION-0.1.0.md)。

- 没有保证长剧本忠实度、人物身份锁定、精确配音/台词、几何四视图或复杂尾帧运动连续性。
- 接口 fixture 只验证提交协议和恢复边界；真实导出用本地可控片段验证媒体处理，不代表模型产物质量。
